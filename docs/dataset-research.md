## Data validation checklist
- Identify provenance and license.
- Check class balance, language coverage and duplicates.
- Remove or anonymize personal information.
- Separate train, validation and holdout test to prevent leakage.
- Avoid treating translated messages as independent test samples when leakage would result.
- Report dataset limits and avoid claims about Kazakh performance without tests.
